Opening Motwi

This takes a moment.

Install Motwi's extension first

Use the browser you watch Twitch in. It works in Chrome, Edge, Brave and Opera.

  1. Download the extension and unzip it to a folder you'll keep.
  2. Open chrome://extensions (Edge: edge://extensions).
  3. Turn on Developer mode.
  4. Choose Load unpacked and pick that folder.
  5. Come back and reload this page.
